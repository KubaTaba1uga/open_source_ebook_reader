Benchmark the startup
=============================

**ID**: <a id="DS-002"></a>DS-002

**Related FFBDs:** [FFBD-002](/design/03_logical_decomposition.md#FFBD-002)

The idea here is to create a small lib which will allow to understand state of our device based on uart and that will be able to issue commands over uart.

This way we can issue button press and make a script which will wait unitl first log appear on UART and will measure time until iun application we will see in log sth like `Starting ebook_reader: OK` printed by script in `/etc/init.d/S99ebook_reader`.

The same library then can be used to measure other parts on the system based on UART.
