External components
===========================

Components to cut out and develop externally, `IT8951 driver`, `Event queue`, `GPIO lib`, `LVGL from XML`.

## Event queue

Event queue needs to allow to:
- broadcast an event
- send, receive an request
- register/unregister for event dynamically


## IT8951 driver

Driver needs to work with Linux userspace and with U-boot.

Driver need to support full refresh and partial refresh and black/white color palette.

Maybe we can support also 16 scale gray? Then our image pipeline could drop all dithering/autothresholding.
How test? Render img with 16 grayscale, display img with driver. We need to test this and revise design and 
rendering pipeline before commiting to 16 level gray scale support.


## GPIO lib

Our driver should work across multiple boards, we can provide this doing first our GPIO lib.

Our lib should abstract away pin definition and settings. You can set GPIO X to pin N in app code.
You declare pin like `EN`, and then which pin serve as this one is configured by some JSON file.
We can allow configuring basic stuff like active low/high or pull-up/pull-down in the config file.


## LVGL from XML

To speed up LVGL development we should have a lib which allow loading view from XML, and then just attaching callbacks.
Then we can just create a view without recompilation and just connect logic to it. This is how GTK does it and this is
very fast to work with.
