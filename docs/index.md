Open Source eBook Reader
====================================

Imagine buying an eBook reader and being able to customize it just like your Linux PC. Don't like the default reading application? Find another one online, install it, and use it. Want to add a feature? Modify the software or write your own.

**The goal of this project is to make eBook readers as easy to customize as ordinary Linux computers.**

I own a Kobo reader, and I really like it. But I wish it had a bigger screen and the freedom to run whatever software I want. For example, I'd like to translate selected words directly in PDFs or automatically synchronize my books using Git. These features are relatively straightforward to implement on Linux, but existing eBook readers don't make this kind of customization easy.

The idea is to build an open-source, Linux-based eBook reader with a large E Ink display, physical buttons, a battery, and an enclosure. It should work as an ordinary eBook reader out of the box, while giving users the freedom to replace the reading application, install additional software, or even reflash the entire operating system.

If you're happy with your Kobo, there's probably no reason to replace it. But if you've ever wished you could treat your eBook reader like your Linux computer, this project is for you.

The closest existing device to what I have in mind is PINE64's PineNote.

## Who is this project for?

If you just want to read books, a Kobo is probably the better choice for 99% of use cases.

But if you're a programmer with unusual ideas about what your reader should do, this project might be for you.

The hardware and software are intended to be open source, so you're free to study, modify, and extend them.

## Getting a device

Building an eBook reader from individual components takes considerable time and effort. For now, I would rather spend that time improving the hardware and software than maintaining comprehensive assembly instructions.

As a result, I plan to offer preassembled devices directly to interested developers, subject to component availability and manufacturing costs.

If you're interested in buying one, feel free to contact me.
